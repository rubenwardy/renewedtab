# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.21.0] - 2026-02-05

### Added
- New **Calendar Widget**: Displays a monthly calendar with the current date highlighted
  - Week starts on Sunday
  - Shows weekday headers (optional)
  - Today's date highlighted with a blue circle
  - Supports internationalization (English and Chinese)

### Changed
- Added Windows compatibility for npm scripts using `cross-env`
- Updated local development configuration to support local API server

## [1.20.2] - 2025-02-05

### Fixed
- Fixed dropdowns in bookmarks bar on Chrome

## [1.20.1] - 2025-02-05
